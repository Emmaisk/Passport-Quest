# Passport-Quest
Une carte du monde interactive où tu explores les pays. Quand tu cliques sur un pays, une petite fiche s’ouvre avec drapeau, capitale, population, langues, monnaie, continent, et d'autres informations : une spécialité locale, un fait insolite, etc.

À terme, l’idée est de pouvoir cliquer sur un pays pour afficher ses infos, découvrir un pays au hasard et ajouter un petit mode quiz.
